## How I work

- **Frame the problem:** turn complex rules and workflows into clear journeys and interaction models.
- **Build to learn:** use functional prototypes to expose edge cases, feasibility limits and real-device behaviour.
- **Design for uncertainty:** make incomplete evidence, recovery paths and human decisions visible.
- **Validate the details:** combine UX evaluation with implementation checks and iterative testing.
- **Collaborate across disciplines:** bring product, engineering, research, analytics and compliance into the decisions.

My independent explorations also include **PIKKO**, an iOS shopping companion using barcode/OCR inputs and recommendation states, and **TALO**, multilingual voice-agent prototypes with interruption recovery, tool calls and human handoff.
